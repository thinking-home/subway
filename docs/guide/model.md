## Протокол: discovery / query / execute / report

Всего между хабом и его потребителями четыре вида обращений:

- **обнаружение** — какие устройства есть и что они умеют;
- **опрос** — в каком состоянии устройство сейчас;
- **команда** — изменить состояние;
- **отчёт** — устройство сообщило об изменении само.

Первые три начинает потребитель, последнее — устройство.
