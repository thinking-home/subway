# Карта пакетов

## Библиотеки

Части хаба поставляются отдельными пакетами NuGet — подключают только те, что нужны для конкретной задачи.

| Пакет | Что внутри | Когда нужен |
| --- | --- | --- |
| [`ThinkingHome.DeviceModel`](/packages/device-model) | Ядро: модель устройств и хост | Всегда — с него начинается любой сценарий |
| [`ThinkingHome.DeviceModel.FluentApi`](/packages/fluent-api) | API: типизированные хендлы устройств для кода | Когда устройствами управляют локальные скрипты |
| [`ThinkingHome.DeviceModel.Remoting.ProxyClient`](/packages/proxy-client) | Сторона дома: подключение к прокси и привязка по одноразовому коду | Когда дом соединяется с облачным прокси |
| [`ThinkingHome.DeviceModel.Remoting.ProxyServer`](/packages/proxy-server) | Сторона прокси: приём соединений и маршрутизация запросов по домам | Когда прокси собирают собственным приложением |
| [`ThinkingHome.DeviceModel.Remoting`](/packages/remoting) | Общий контракт обмена между этими двумя сторонами | Приходит зависимостью, отдельно не подключается |
| [`ThinkingHome.Alice`](/packages/alice) | Адаптер Яндекс Алисы: перевод модели в её формат и обратно | Когда дом подключают к Алисе |
| [`ThinkingHome.DeviceModel.Drivers.Stubs`](/packages/drivers-stubs) | Стабовые драйверы: виртуальные лампы, датчики, счётчики | Чтобы посмотреть работу хаба без физических приборов |

Драйверы устройств живут в отдельных пакетах — по одному на протокол. Их подключают так же: нужен MQTT — берут пакет с
драйвером MQTT.

## Приложения

Кроме библиотек есть два готовых приложения — их не подключают к проекту, а разворачивают.

| Приложение | Что это | Когда нужно |
| --- | --- | --- |
| [`ThinkingHome.DeviceModel.Proxy`](/apps/proxy) | Прокси, готовый к развёртыванию: принимает соединения от домов и обслуживает запросы Алисы | Когда прокси не хочется собирать самому |
| [`ThinkingHome.Home`](/apps/home) | Домашний сервер с набором устройств-заглушек | Чтобы посмотреть, как всё работает, без единого настоящего прибора |
